# QA Portfolio - Renato Freitas

Este repositório contém meu portfólio de Quality Assurance (QA), com foco em testes manuais, testes exploratórios e automação de testes.

---

## 📌 Objetivo

Demonstrar habilidades práticas em QA, incluindo:

- Criação de casos de teste manuais
- Execução de testes funcionais
- Testes exploratórios (exploração de cenários fora do fluxo esperado)
- Documentação de bugs e evidências
- Automação de testes com Cypress

---
